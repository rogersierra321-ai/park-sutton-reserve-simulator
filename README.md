# Capital Projects & Reserve Fund Simulator

A single static page (`index.html`). No build step is needed.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project**, import the repository, and set **Framework Preset** to **Other**.
3. Leave the build command and output directory empty, then click **Deploy**.

Or, from this folder with the Vercel CLI: `npx vercel --prod`
